# Flight Delay and Cancellation Analysis

This project analyzes U.S. airline flight delay and cancellation data from 2019 to 2023 to uncover trends, operational challenges, and factors affecting flight punctuality.

Using Python and data analysis techniques, the project explores:
- Flight delay patterns
- Cancellation trends
- Airline performance
- Airport congestion
- Seasonal impacts
- Time-based operational behavior

The analysis provides actionable insights and recommendations for both airlines and passengers.

---

# Project Objectives

- Clean and preprocess raw flight datasets
- Perform Exploratory Data Analysis (EDA)
- Visualize delay and cancellation trends
- Identify factors affecting flight punctuality
- Generate actionable insights and recommendations

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

# Dataset Information

The dataset contains U.S. airline flight data from 2019 to 2023, including:

- Airline carriers
- Origin and destination airports
- Departure and arrival delays
- Cancellation status
- Cancellation reasons
- Flight distance
- Air time
- Flight dates and schedules

The dataset was used to analyze operational performance and identify patterns affecting airline reliability across the United States.
